# 课程综述论文要求与验收标准

## 一、基本信息

| 项目 | 要求 |
|---|---|
| 课程 | 专业写作基础 |
| 中文题目 | 《无线边缘网络中联邦学习通信效率优化方法研究综述》 |
| 暂定英文题目 | *A Review of Communication-Efficiency Optimization Methods for Federated Learning in Wireless Edge Networks* |
| 论文类型 | 本科课程文献综述 |
| 主要任务 | 梳理已有研究、建立分类框架、比较方法、总结局限、展望发展方向 |
| 非目标 | 原创算法、原创实验、虚构数据或原创研究式贡献声明 |

## 二、量化要求

| 指标 | 最低/允许范围 | 项目目标 | 统计口径 |
|---|---:|---:|---|
| 中文正文字数 | 4500～5500 字 | 约 5000 字 | 不含摘要和参考文献 |
| 参考文献总数 | 不少于 40 篇 | 42～48 篇 | 仅计入最终已核验文献 |
| 中文学术文献 | 尽量包含 | 12～18 篇 | 必须为可核验学术文献 |
| 近五年文献 | 必须包含 | 覆盖 2022—2026 年 | 同时保留经典早期文献 |
| 中文摘要 | 约 150 字 | 信息完整、表述简洁 | 不计入正文字数 |
| 中文关键词 | 4～5 个 | 4～5 个 | 与主题及分类框架一致 |
| 英文要素 | 必须包含 | 英文标题、摘要、关键词 | 与中文内容语义一致 |

## 三、内容结构要求

正文至少设置以下部分，标题层级可在详细提纲阶段调整：

1. 引言
2. 基础与问题定义
3. 通信效率优化方法分类
4. 方法比较
5. 挑战与趋势
6. 结论

结构验收关注：各部分职责清楚；分类维度一致；比较有统一指标或维度；挑战和趋势由前文证据推导；结论不引入未论证的新观点。

## 四、文献与证据要求

### 4.1 来源组合

- 同时覆盖领域奠基或经典早期研究，以及 2022—2026 年的新近研究。
- 中文文献目标 12～18 篇，其余选择高质量英文期刊、会议论文及必要的权威综述。
- 不以数量替代质量；主题弱相关、来源不明或无法核验的条目不得为满足数量而纳入。

### 4.2 元数据核验

最终参考文献中的每一条至少应完成以下核验：

- 作者；
- 题名；
- 期刊、会议、学位授予单位或出版社；
- 发表年份；
- 文献类型标识 [J]、[C]、[D]、[M] 等；
- 适用时核验卷、期、页码、DOI 和稳定 URL。

元数据不完整或相互冲突时，状态必须标为“待核验”；待核验条目不得进入最终参考文献，也不得支撑最终稿中的关键事实。

### 4.3 论断可追溯性

- 具体数据、比较结论、已有方法的优缺点和他人观点均须附可核验引用。
- 引用必须真实支持相邻论断，避免一条文献笼统支撑整段多个不同事实。
- 归纳性结论应明确体现其综合来源；推断不得伪装为来源原话。
- 禁止伪造作者、标题、来源、年份、卷期、页码、DOI、URL、算法、实验和结果。

## 五、引用与参考文献格式

- 正文采用顺序编码引用，如 [1][2]。
- 参考文献按正文首次出现顺序编号。
- 各条目按其类型标注 [J]、[C]、[D]、[M] 等。
- 同一来源在全文使用一致的编号和元数据。
- 具体著录细则等待课程模板确认；在确认前不得假定某一国标或期刊模板已经获批。

## 六、图表要求

- 论文应图文并茂，优先制作原创归纳图、分类框架图、方法比较表或研究脉络图。
- 不直接复制他人图片；如确有必要引用，须核查授权条件并规范注明来源。
- 每幅图表应有编号、标题/图注，并能追溯到其信息来源或制作依据。
- 图表中的数字、方法属性和比较结论与正文、证据矩阵保持一致。
- 可编辑源文件和导出文件统一保存在 `figures/`。

## 七、写作边界

- 全文按“综述”身份表述，可使用“本文综述/归纳/比较……”，不得使用“本文提出一种新算法”等原创研究式表述。
- 不虚构实验设计、数据集、消融实验、性能结果或统计显著性。
- 不把尚未核验的线索写成确定事实。
- 对证据不足、研究结论不一致或适用条件受限的内容，应如实说明不确定性和边界。

## 八、阶段 0 验收标准

阶段 0 仅在以下各项均满足时完成：

- [x] 根目录存在 `AGENTS.md` 和 `PROGRESS.md`。
- [x] 存在 `requirements/course_requirements.md`。
- [x] 已建立 `literature/`、`outline/`、`draft/`、`figures/`、`final/`。
- [x] 所有硬性要求已写入长期项目规范。
- [x] 已定义断点续作读取顺序、状态记录和下一阶段关口。
- [x] 已明确本阶段不进行大规模检索、不撰写正文。

## 九、最终交付验收清单

以下清单供后续阶段使用，本阶段不执行：

- [ ] 中文正文为 4500～5500 字，摘要和参考文献未计入。
- [ ] 中文摘要约 150 字，中文关键词 4～5 个。
- [ ] 英文标题、英文摘要、英文关键词齐全且与中文对应。
- [ ] 六个必需正文部分齐全、逻辑连贯。
- [ ] 最终参考文献不少于 40 篇，目标达到 42～48 篇。
- [ ] 中文学术文献达到或合理接近 12～18 篇目标。
- [ ] 同时覆盖经典早期文献和 2022—2026 年文献。
- [ ] 所有最终参考文献均已核验，不含“待核验”条目。
- [ ] 作者、题名、来源、年份、卷期页码、DOI/URL 等元数据无已知伪造或未说明冲突。
- [ ] 所有具体数据、结论和他人观点均有可追溯来源。
- [ ] 正文引用采用顺序编码，编号与参考文献一一对应。
- [ ] 参考文献类型标识完整，格式遵循最终确认的课程规范。
- [ ] 图表以原创归纳为主，编号、图注、来源和可编辑源文件齐全。
- [ ] 无“本文提出新算法”等不符合综述性质的声明。
- [ ] 无虚构实验、算法、结果或数据。
- [ ] 完成一次写作后完整性核验，并对最终修订稿重新核验。
- [ ] 最终稿及其引用表、图表源文件和核验记录之间可追溯。
