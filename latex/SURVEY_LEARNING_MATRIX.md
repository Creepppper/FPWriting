# 示例综述结构学习矩阵

> 阶段：LaTeX 重构阶段 1。  
> 范围：逐篇检查 `assets/surveys/` 中 12 篇综述的摘要、引言、主要章节、分类图、系统模型图、比较表、结论及 PDF 权利信息。

## 1. Lim 等（2020）

- **论文题目与年份**：*Federated Learning in Mobile Edge Networks: A Comprehensive Survey*（2020）。
- **本地文件**：`01_lim_2020_mobile_edge_fl_survey.pdf`。
- **综述范围**：移动边缘网络中的联邦学习，覆盖基础流程、通信成本、资源分配、隐私安全及边缘应用。
- **分类依据**：先按部署问题分为通信成本、资源分配和隐私安全，再按每类问题的解决机制细分。
- **主要章节组织**：背景与 FL 基础 → 通信成本 → 资源分配 → 隐私安全 → 移动边缘应用 → 挑战与未来方向。其逻辑是先定义场景，再处理系统瓶颈，最后讨论应用与研究缺口。
- **最值得学习的图或表**：Fig. 2 综述分类图、Fig. 4 一般 FL 训练流程、Table IV 通信成本降低方法、Table V 资源分配方法。
- **可借鉴的写作方式**：引言先比较已有综述并声明本文范围；方法章节在每一大类后总结“共同收益—共同限制—后续问题”；系统图与 FedAvg 公式相邻出现。
- **不适合本论文的部分**：隐私安全和移动边缘应用占比过大；当前论文只应把安全作为通信附加约束，不应复制其宽综述范围。

## 2. 孙兵等（2022）

- **论文题目与年份**：《移动边缘网络中联邦学习效率优化综述》（2022）。
- **本地文件**：`02_sun_2022_mobile_edge_efficiency_cn.pdf`。
- **综述范围**：移动边缘网络中的 FL 效率，包含通信优化、训练优化和安全隐私保护。
- **分类依据**：以影响“效率”的问题来源分类；通信侧再分边缘协调、模型压缩等，训练侧再分设备选择、资源协调、聚合控制和数据优化。
- **主要章节组织**：深度学习、边缘计算和 FL 基础 → 通信优化 → 训练优化 → 安全隐私 → 总结与展望。各方法大类由比较表收束。
- **最值得学习的图或表**：表 3 通信优化方案比较、图 15 传统多址与空中计算对比、表 4 训练优化方法比较。
- **可借鉴的写作方式**：先解释“效率”由哪些变量构成，再建立分类；每类不仅介绍方法，还明确优化目标、优点和条件；中文术语和科技写作风格适合作为表达参照。
- **不适合本论文的部分**：谷歌趋势、国内外论文数量、深度学习神经网络基础图与同态加密图对当前主题贡献低；安全隐私不能成为独立主线。

## 3. Zhao 等（2023）

- **论文题目与年份**：*Towards Efficient Communications in Federated Learning: A Contemporary Survey*（2023）。
- **本地文件**：`03_zhao_2023_efficient_communications_survey.pdf`。
- **综述范围**：FL 中的高效通信，既讨论模型更新压缩，也讨论不可靠/噪声信道和通信资源配置。
- **分类依据**：按通信问题所在层次分为通信效率、通信环境和通信资源三条主线；通信效率内部再按量化、稀疏、蒸馏等机制分类。
- **主要章节组织**：FL 流程与通信挑战 → 通信效率方法 → 通信环境问题 → 资源配置 → 比较、挑战与未来方向。Fig. 1 先把挑战定位到系统流程，Fig. 2 再给全文导航。
- **最值得学习的图或表**：Fig. 1 典型通信框架与五类挑战、Fig. 2 综述主体结构、Table 1—3 三组统一字段比较表。
- **可借鉴的写作方式**：公式、分类图和比较表使用同一组问题变量；三张表分别回答“传什么、在什么信道传、如何配置资源”，避免把算法层和无线层混为一谈。
- **不适合本论文的部分**：篇幅和数学深度远超本科 5000 字限制；不能照搬其完整通信理论分类或大表。

## 5. Xiao 等（2024/2025）

- **论文题目与年份**：*Over-the-Air Federated Learning: Status Quo, Open Challenges, and Future Directions*（公开稿 2023，正式发表 2024/2025）。
- **本地文件**：`05_ota_fl_2023_status_survey.pdf`。
- **综述范围**：空中联邦学习，重点是利用无线多址信道叠加完成模型/梯度聚合。
- **分类依据**：按物理层系统配置分为单天线 OTA-FL、多天线 OTA-FL、RIS 辅助 OTA-FL，并讨论可信、安全和隐私。
- **主要章节组织**：OTA-FL 动机与系统模型 → SISO 的用户选择/功率控制 → 多天线联合设计 → RIS 辅助 → 安全隐私 → 经验、挑战与方向 → 结论。
- **最值得学习的图或表**：Fig. 1 OTA-FL 系统模型、Fig. 2 多天线联合设计、Table II—V 对设计目标、算法、优点和弱点的统一比较。
- **可借鉴的写作方式**：系统图之后立即给出信号模型；每类方法都以优化目标、设计变量和物理约束组织；说明收益后紧接同步、信道估计、噪声和功率限制。
- **不适合本论文的部分**：多天线、RIS 和安全专题细节过深；当前论文第 3.4 节只需解释基本机理、主要指标和适用边界。

## 13. 跨综述结构结论

### 13.1 可迁移的共同写法

1. **先定义比较口径，再分类方法**：Lim、Zhao、Le 和 Yan 都先给系统模型或成本来源，后续分类才有共同变量。
2. **分类图只负责导航**：高质量综述不会让一张树状图承担全部论证；分类图之后仍有机制图、公式和比较表。
3. **每类使用相同分析模板**：问题来源 → 共同机理 → 代表工作 → 指标 → 收益 → 代价/假设 → 适用场景。
4. **表格承担横向比较**：Zhao、Zhang、Kunjumon 和 Yan 的表格均使用稳定字段，而不是按年份罗列论文。
5. **趋势从限制推出**：Wu、Asad 和 Yan 先总结静态假设、附加开销或部署不足，再提出动态拓扑、联合优化和真实平台验证。
6. **图必须进入论证链**：Xiao 的系统图直接引出信号模型；Yan 的系统图直接引出能耗变量；Pouriyeh 的图注说明完整训练轮次。

### 13.2 对本论文结构的具体约束

- 第 1 章应比较已有综述的关注点，准确说明本文采用“通信成本组成与系统层次”双重分类，而不是声称此前没有相关综述。
- 第 2 章应以一张系统—消息图和一组成本公式统一轮数、比特量、时延、能耗和控制开销。
- 第 3 章应把客户端选择/频率控制与无线资源分配拆开，形成算法层、链路层和拓扑层的递进。
- 第 4 章必须有统一比较表，并给出面向瓶颈的场景选择逻辑；不能用不同实验的百分比直接排名。
- 第 5 章只保留由比较表暴露出来的指标不统一、附加开销、动态环境和真实部署问题。
- 摘要和结论最后重写；摘要说明分类依据，结论回答不同瓶颈下的方法选择，不引入新文献。
